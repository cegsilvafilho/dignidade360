# Dignidade 360 Enterprise - Programa de teste

Programa local demonstrativo para testar a versão robusta da Dignidade 360 no Codex.

## Como abrir

Com o servidor local rodando na pasta principal:

`http://localhost:8080/dignidade-360-enterprise-teste/`

## Perfis de teste

- Paciente: check-in, painel, plano e consentimentos.
- Cuidador: check-in assistido e permissões.
- Profissional: fila, alerta, conduta e resolução.
- Gestor: indicadores, unidades, linhas e auditoria.
- Admin: operação, governança e alertas.

## Funcionalidades

- Login simulado por perfil.
- Check-in paliativo.
- Cálculo demonstrativo de prioridade.
- Criação automática de alertas.
- Fila assistencial com SLA.
- Conduta e resolução de alerta.
- Timeline longitudinal.
- Consentimentos.
- Auditoria.
- Indicadores gerenciais.
- Gestão de linhas de cuidado.

## Limite

Este programa usa dados fictícios e `localStorage`. Não é uma plataforma clínica real e não deve ser usado com dados reais de pacientes.
